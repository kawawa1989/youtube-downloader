# 05. ドライランオプション

## 概要

`--dry-run` で実際のダウンロードを行わず、取得予定の動画タイトルと出力先パスだけを表示する。
プレイリストや一括処理の前に対象と件数を確認でき、誤実行を防げる。

## 実施内容

- パーサに `--dry-run` を `store_true` で追加する
- `downloader.py` に `preview(url, outdir, bitrate, playlist)` を実装する
  - `YoutubeDL.extract_info(url, download=False)` でメタ情報のみ取得する
  - 取得したタイトルと `outtmpl` から、生成予定のファイルパスを組み立てる
- 1件ごとに「タイトル / 再生時間 / 出力予定パス」を表示する
- 最後に対象件数の合計を表示する
- ドライラン時はファイルを一切作成せず、終了コード 0 で終わる

## 完了条件

- `--dry-run` 付きで実行してもファイルが1つも生成されない
- 単一 URL・プレイリスト・`--file` のいずれでも対象一覧が表示される
- 表示された出力予定パスが、同条件で実際に実行したときの生成先と一致する
