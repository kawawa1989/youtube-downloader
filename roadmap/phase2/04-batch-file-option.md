# 04. URL 一括処理オプション

## 概要

`-f/--file` で URL を列挙したテキストファイルを渡し、まとめて処理できるようにする。
複数の動画を1件ずつコマンド実行するのは手間であり、実利用で最も使う入力経路になる。

## 実施内容

- パーサに `-f` / `--file` を追加し、位置引数 `url` を任意（`nargs="?"`）に変更する
- `url` と `--file` のどちらも指定されない場合はエラー、両方指定された場合は両方を処理対象にする
- ファイルを UTF-8 で読み込み、以下を除外して URL リストを組み立てる
  - 空行
  - 先頭が `#` のコメント行
  - 前後の空白（`strip()`）
- リストを順に `download()` へ渡す
- 1件の失敗で中断せず次の URL へ進む（詳細な集計はフェーズ4で実装）
- 各件の処理前に `[3/10] <URL>` 形式の進行表示を出す

## 完了条件

- 5件程度の URL を書いたファイルを渡すと、全件が順に処理される
- 空行とコメント行が無視される
- 存在しないファイルを指定すると、パスを含む日本語エラーとともに終了コード 1 で終わる
- URL も `--file` も指定しない場合に使い方が表示される
