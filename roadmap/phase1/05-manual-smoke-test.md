# 05. 実 URL での動作確認

## 概要

フェーズ1の成果物を実際の YouTube URL に対して通しで動かし、MVP が成立していることを確認する。
ここで検出した問題はフェーズ2以降へ持ち越さず、原則その場で修正する。

## 実施内容

- 権利上問題のない短い動画（自分の投稿、CC ライセンス、公式のサンプル等）の URL を用意する
- `python -m ytmp3 <URL>` を実行し、エラーなく完了することを確認する
- 生成された mp3 を実際に再生し、音声が最後まで欠けなく入っていることを確認する
- `ffprobe <file>` でコーデック、ビットレート、再生時間を確認し、元動画の長さと一致することを確認する
- 日本語タイトルの動画でも実行し、ファイル名が文字化けしないことを確認する
- 確認結果と使用した URL を作業メモとして控える

## 完了条件

- 英語タイトル・日本語タイトルの両方で mp3 の生成に成功している
- 生成物が再生でき、再生時間が元動画と一致している
- 手順どおりに実行して失敗するケースがこの時点で残っていない
