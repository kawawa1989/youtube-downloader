# 01. エラー分類と日本語メッセージ

## 概要

yt-dlp が送出する例外を原因別に分類し、利用者が次に何をすべきか判断できる日本語メッセージへ変換する。
スタックトレースがそのまま出る状態では、原因が利用者側か動画側か切り分けられない。

## 実施内容

- `downloader.py` に例外種別を表す `DownloadError` 系の分類を定義する
- `yt_dlp.utils.DownloadError` のメッセージを解析し、以下に分類する
  - 非公開・削除済み動画 → 「この動画は非公開または削除されています」
  - 地域制限 → 「この動画はお住まいの地域では視聴できません」
  - 年齢制限 → 「年齢制限付きの動画のため取得できません」
  - 無効な URL → 「URL の形式が正しくありません」
  - ネットワークエラー → 「ネットワークに接続できません」
  - yt-dlp の仕様変更起因と思われるもの → 「yt-dlp の更新が必要な可能性があります: pip install -U yt-dlp」
- 分類できない例外は原文メッセージをそのまま添えて表示する
- 各メッセージに対象 URL を併記する

## 完了条件

- 存在しない動画 ID の URL を渡すと、分類済みの日本語メッセージが表示される
- 不正な文字列を URL として渡すと、形式エラーのメッセージが表示される
- いずれの場合も Python のスタックトレースが利用者に露出しない
- 分類外の例外でも原文メッセージが確認でき、原因調査ができる
