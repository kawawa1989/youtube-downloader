# 04. 処理サマリと終了コード

## 概要

一括処理の結果を最後にまとめて表示し、終了コードで成否を伝える。
件数が多いと途中の出力を追えないため、最終行だけ見れば状況がわかる状態にする。
シェルスクリプトからの呼び出しに応えるため終了コードも規約化する。

## 実施内容

- 処理結果を保持する集計オブジェクトを用意する（成功・失敗・スキップ）
- 全処理の終了後にサマリを表示する
  - `完了: 成功 8件 / スキップ 1件 / 失敗 1件`
  - 失敗がある場合は、URL とエラー理由を一覧で表示する
- 終了コードを規定する
  - 0: 全件成功（スキップのみは成功扱い）
  - 1: 1件以上の失敗あり、または起動時エラー
  - 2: 引数エラー（argparse 標準）
  - 130: ユーザーによる中断
- 単一 URL 処理時はサマリを省略し、冗長な出力を避ける
- 失敗した URL だけを再実行用にファイル出力する `--failed-output PATH` を追加する

## 完了条件

- 一括処理の最後に成功・スキップ・失敗の件数が表示される
- 失敗があると URL と理由が一覧表示され、`echo $?` が 1 を返す
- 全件成功時は `echo $?` が 0 を返す
- `--failed-output` で出力したファイルを、そのまま `--file` に渡して再実行できる
