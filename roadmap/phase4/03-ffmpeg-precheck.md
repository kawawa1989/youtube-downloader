# 03. ffmpeg の事前チェック

## 概要

ffmpeg が未導入の環境では、ダウンロード完了後の変換段階で初めて失敗する。
無駄なダウンロードを避けるため、起動直後に存在を確認する。

## 実施内容

- `cli.py` の `main()` 冒頭で `shutil.which("ffmpeg")` を確認する
- 見つからない場合は以下を表示し、終了コード 1 で終わる
  - 「ffmpeg が見つかりません。mp3 への変換に必要です。」
  - 「導入方法: brew install ffmpeg」
- `--dry-run` 時はチェックをスキップする（変換を行わないため）
- 併せて yt-dlp のバージョンを取得し、半年以上古い場合は `pip install -U yt-dlp` を促す警告を出す（処理は継続する）

## 完了条件

- ffmpeg が PATH にない状態で実行すると、ダウンロードを開始せず導入手順を表示して終了コード 1 で終わる
- ffmpeg がある通常環境では、追加のメッセージなく処理が進む
- `--dry-run` は ffmpeg の有無にかかわらず動作する
