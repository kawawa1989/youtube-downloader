# 06. README 整備と git 初期コミット

## 概要

導入手順・使い方・注意事項をまとめ、リポジトリとして成立する状態にする。
時間が経って自分が読み返したときにも、環境構築からやり直せることを目標にする。

## 実施内容

- `README.md` を作成し、以下を記載する
  - 概要と前提（Python 3.13 以上、ffmpeg）
  - セットアップ手順（venv 作成、`pip install -r requirements.txt`、`brew install ffmpeg`）
  - 使い方（単一 URL、ビットレート指定、プレイリスト、`--file` 一括、`--dry-run`）
  - 全オプションの一覧表
  - トラブルシューティング（取得に失敗する場合はまず `pip install -U yt-dlp`）
  - 利用上の注意: 自分がアップロードした動画・権利処理済み音源・CC ライセンス素材など、権利的に問題のない範囲で利用すること。YouTube の利用規約上、一般の動画のダウンロードには権利者の許諾が必要である旨
- `.gitignore` の内容を最終確認する（`.venv/`、`downloads/`、`__pycache__/`、`.DS_Store`）
- `git add` して初期コミットを作成する

## 完了条件

- README の手順どおりに進めれば、クリーンな環境でセットアップから実行まで到達できる
- 全 CLI オプションが README に記載されている
- 利用上の注意が明記されている
- `git log` に初期コミットがあり、`git status` がクリーンである
- `downloads/` と `.venv/` がコミットに含まれていない
