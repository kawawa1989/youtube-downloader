# 05. 重複ファイルのスキップ

## 概要

出力先に同名の mp3 が既にある場合、再ダウンロードを行わずスキップする。
一括処理の再実行時に、全件を取り直す無駄を避けるのが目的。

## 実施内容

- ダウンロード開始前に、サニタイズ後の出力先パスの存在を確認する
  - `extract_info(download=False)` でタイトルを取得し、想定パスを組み立てる
- 既存ファイルがある場合は `スキップ: <ファイル名> (既に存在)` を表示して次へ進む
- `--force` オプションを追加し、指定時は既存ファイルを上書きする
- スキップした件数を集計し、処理結果として保持する（サマリ表示はフェーズ4で行う）
- ファイルサイズ 0 の壊れた残骸は既存とみなさず、再取得の対象にする

## 完了条件

- 同じ URL を2回実行すると、2回目はスキップされ、ファイルの更新日時が変わらない
- `--force` を付けると2回目も再ダウンロードされ、ファイルが上書きされる
- サイズ 0 のファイルが置かれている場合は再ダウンロードされる
- `--file` での一括処理で、既存分がスキップされ未取得分のみ処理される
