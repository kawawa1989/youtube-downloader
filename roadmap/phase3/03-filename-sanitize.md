# 03. ファイル名のサニタイズ

## 概要

動画タイトルをそのままファイル名にすると、macOS で扱いづらい名前や長すぎる名前になる。
安全かつ可読なファイル名へ正規化する。日本語タイトルは読めるまま残すことを優先する。

## 実施内容

- `downloader.py` に `sanitize_filename(name)` を実装する
  - macOS で問題になる `/` と `:` を全角または `-` に置換する
  - 制御文字と前後の空白・ドットを除去する
  - ファイル名部分を 150 文字程度で切り詰める（拡張子は保持する）
  - 置換の結果が空文字になる場合は動画 ID をファイル名に使う
- yt-dlp の `restrictfilenames` は使わない（日本語が失われるため）
- `outtmpl` を直接テンプレートに任せず、`%(title)s` に対して上記処理を適用する仕組みにする
  - `outtmpl` を `%(id)s` ベースにして後からリネームする、もしくは `prepare_filename()` の結果を加工する
- タイトル重複時は末尾に ` (2)`、` (3)` を付与する

## 完了条件

- `/` や `:` を含むタイトルの動画で、エラーなく保存できる
- 日本語タイトルがそのまま読める形でファイル名に残る
- 200 文字を超えるタイトルでも保存に成功する
- 同名タイトルの動画を2回処理すると、連番付きの別ファイルとして保存される
